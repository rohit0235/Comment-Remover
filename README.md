# Comment Remover

 # 🧹 Code Comment Remover

A simple web-based tool to remove comments from source code in various languages like Python, C, C++, Java, and JavaScript.

---

## 🔥 Why This Project?

With the rise of AI coding assistants, there's been a surge in auto-generated comments — not all of them are helpful. This tool lets you **clean your code** by removing unnecessary comments, making it leaner and more production-ready.

---

## ✨ Features

- 🐍 Python comment removal using `tokenize` for accuracy
- 💻 C, C++, Java, JavaScript support via regular expressions
- 🌐 Web interface built with HTML + TailwindCSS
- ⚙️ Backend powered by Flask
- 📦 Easy to set up locally


## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/code-comment-remover.git
cd code-comment-remover
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```
**3. Run the app**
```bash
python app.py

```
Then open your browser and go to:
### 2. Run
```bash
http://localhost:5000/static/index.html
```
